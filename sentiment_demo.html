How this differs from the notebook: the real project trains TF-IDF + Logistic Regression / SVM / Random Forest in scikit-learn, which can't run inside a browser. This page reimplements the same clean_text() cleaning steps in JavaScript, then scores the cleaned text with a small hand-built positive/negative word lexicon and simple negation handling (so "not good" flips instead of just matching "good"). It's a stand-in for live demo purposes — the notebook's trained model is the one the accuracy/F1 numbers in the report actually refer to.
